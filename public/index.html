Cara kerja

Tiga langkah, tanpa daftar akun.

Salin link

Buka aplikasinya, tekan Bagikan lalu Salin link. Teks share lengkap juga boleh ditempel.

Proses

Server (Python + yt-dlp) membaca link dan mencari semua kualitas video, audio, atau gambar yang tersedia.

Download

Pilih kualitas. Penggabungan video + audio dan konversi MP3 berjalan langsung di browser kamu.

Detail teknis
  • Extractor: Python + yt-dlp + plugin DownloadAja (Douyin, Kuaishou, Threads, Bilibili, pixiv, serta foto slide & Live Photo dari TikTok, Xiaohongshu, X, Instagram, Bluesky, Weibo) di Vercel Functions.
  • Proxy streaming: Cloudflare Worker dengan link bertanda tangan HMAC, dukung resume, tanpa batas ukuran.
  • Merge, ugoira & MP3: ffmpeg.wasm + lamejs di browser — file tidak disimpan di server mana pun.
  • Android: Kotlin + Jetpack Compose + youtubedl-android (Python & yt-dlp jalan di HP) + FFmpeg minimal hasil build sendiri, pratinjau dengan Media3 ExoPlayer.

FAQ

Gratis? Ada batasan?

Gratis. Supaya adil ada batas wajar jumlah permintaan per menit.

Kenapa YouTube gagal di web?

YouTube, Bilibili, dan beberapa platform lain memblokir IP server cloud. Gunakan aplikasi Android — engine berjalan dari jaringan kamu sendiri sehingga jauh lebih stabil.

Bisa ambil foto slide / Live Photo?

Bisa. Untuk TikTok (mode foto), Douyin, Xiaohongshu, Kuaishou, X, Instagram, Threads, Bluesky dan Weibo, semua foto muncul di tab Galeri. Ketuk untuk memilih satu per satu, tekan ikon perbesar untuk melihat. Live Photo bisa diunduh sebagai foto, video, atau keduanya. Lebih dari satu file otomatis dibungkus ZIP.

Bisa download dari pixiv?

Bisa: ilustrasi dan manga (semua halaman, resolusi asli, sekaligus dalam ZIP) serta ugoira yang otomatis dijadikan MP4 atau GIF. Karya R-18 butuh login pixiv sehingga tidak didukung.

Konten privat atau premium?

Tidak didukung. DownloadAja hanya mengambil konten publik; konten berbayar/DRM tidak bisa diunduh.

Apakah file disimpan di server?

Tidak. Server hanya membaca info link. File mengalir langsung dari CDN platform ke perangkat kamu, dan proses merge/MP3 berjalan di browser.
