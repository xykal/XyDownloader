Detail teknis (buat yang penasaran)
  • Extractor: Python + yt-dlp + plugin XyDownloader (Douyin, Kuaishou, Threads) di Vercel Functions.
  • Proxy streaming: Cloudflare Worker (link bertanda tangan HMAC, dukung resume/Range, tanpa batas ukuran).
  • Merge & MP3: ffmpeg.wasm + lamejs di browser — file kamu tidak disimpan di server mana pun.
  • Android: Kotlin + Jetpack Compose + youtubedl-android (Python, yt-dlp, FFmpeg jalan langsung di HP).

FAQ

Gratis? Ada batasan?

Gratis. Supaya adil, ada batas wajar permintaan per menit per pengguna.

Kenapa YouTube kadang gagal di web?

YouTube mengunci link download ke alamat IP server dan sering menahan server cloud (anti-bot). Web tetap mencoba lewat jalur server; untuk hasil paling stabil pakai aplikasi Android.

Bisa download konten privat / premium?

Tidak. XyDownloader hanya mengambil konten publik. Konten berbayar/DRM (misalnya Vidio Premier, iQIYI VIP) tidak didukung.

File disimpan di server?

Tidak. Server hanya membaca info link. File mengalir langsung dari CDN platform ke perangkat kamu lewat proxy streaming, dan proses merge/MP3 berjalan di browser.

Link Douyin/Xiaohongshu tidak bisa?

Pakai link share asli dari aplikasinya (mis. v.douyin.com/… atau xhslink.com/…). Teks share lengkap juga boleh langsung ditempel — link-nya diambil otomatis.
